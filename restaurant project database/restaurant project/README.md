# Sixty-Three Social

This repository is for our student restaurant management project. The `database/` folder includes the MySQL tables, sample data, Python database functions, and tests.

**Setup:** Read `Team_Setup_Guide.docx` before running anything. It explains how to set up Aiven MySQL, Python, and GitHub access.

The database is not the complete website. The front-end and Flask integration are still team work in progress.

**Important:** Never commit `.env`, passwords, or SSL certificate files. Use `.env.example` as a template and keep your real connection details private.
